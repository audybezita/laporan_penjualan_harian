Struktur proyek

  • index.php — entry, arahkan ke login/dashboard
  • login.php, setup.php — autentikasi pemilik
  • config/database.php.example — konfigurasi koneksi PDO
  • database/donat_ns.sql — file SQL untuk diimpor

  • admin/ — halaman admin (dashboard + API)
